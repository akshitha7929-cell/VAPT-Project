# 🔐 Vulnerability Assessment and Penetration Testing (VAPT)

## 📌 Project Overview

This project focuses on performing a **Vulnerability Assessment and Penetration Testing (VAPT)** on the **Damn Vulnerable Web Application (DVWA)**, a deliberately insecure web application created for cybersecurity training and educational purposes. The assessment was conducted in a safe and controlled environment using **Kali Linux** installed on **Oracle VirtualBox**.

The primary objective of this project is to identify security vulnerabilities, understand how attackers exploit them, analyze their potential impact, and recommend mitigation techniques based on industry best practices. The project provides practical exposure to ethical hacking methodologies and web application security concepts.

The project follows a structured penetration testing process:

5. Result Analysis
6. Mitigation Recommendations

---

## 🔍 Vulnerabilities Tested

### 1. SQL Injection

* Tested for insecure SQL queries.
* Demonstrated authentication bypass and unauthorized database access.

### 2. Brute Force Attack

* Tested login authentication using valid and invalid credentials.
* Evaluated password security.

### 3. Command Injection

* Demonstrated execution of operating system commands through vulnerable input fields.

### 4. File Upload Vulnerability

* Tested improper validation of uploaded files.

### 5. File Inclusion Vulnerability

* Evaluated Local File Inclusion (LFI) behavior.

Each vulnerability was analyzed for its impact, severity, and recommended mitigation techniques.
